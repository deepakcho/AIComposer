# `@ai-composer/web-component`

Framework-independent `<ai-composer-editor>` custom element for embedding an AI chat input or
prompt editor in any web application. It exposes the core editor through element properties and
dispatches editor events as DOM custom events.

```sh
npm install @ai-composer/core @ai-composer/dom @ai-composer/web-component
```
