# `@ai-composer/themes`

Optional CSS design tokens and default, dark, and compact themes for AI Composer. The editor works
without this package; use the themes for a quick, polished starting point or customize the CSS
variables to match your product.

```sh
npm install @ai-composer/themes
```

```ts
import '@ai-composer/themes/css/tokens.css';
import '@ai-composer/themes/css/default.css';
import '@ai-composer/themes/css/dark.css'; // optional dark theme
```
