# `@ai-composer/testing`

Shared contract-test helpers for AI Composer adapters. Use this package when implementing or
maintaining an adapter to check that it follows the common editor behavior.

```sh
npm install -D @ai-composer/testing
```

The contract suite is intended for adapter authors; most application developers do not need to
install it.
